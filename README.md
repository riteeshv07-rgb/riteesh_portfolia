# Riteesh - Software Engineer Portfolio

An interactive, 3D cyber-luxe software engineering portfolio featuring Three.js WebGL graphics, dynamic perspective card tilt physics, pixel art UI accents, and automatic day/night theme detection.

## 🚀 Live Demo
Once deployed to GitHub Pages, the website will be available at:
`https://riteeshv07-rgb.github.io/Riteresh/`

## ✨ Features
- **Interactive 3D WebGL Canvas (Three.js):** Floating wireframe geometries and 3D particle swarm that react to cursor movement and real-time lighting.
- **3D Card Perspective Tilt:** Physical perspective transforms and holographic glare highlights that follow the user's cursor.
- **Vertical Navigation Dock:** Accessible left-hand sidebar with ScrollSpy active-section highlighting and a mobile responsive drawer.
- **Dynamic Night / Day Theming:** Automatic detection of browser default themes via CSS `prefers-color-scheme` media queries with manual toggle control.
- **Semantic HTML5 Architecture:** Clean, modular structure with accessible ARIA landmarks.

## 📁 Project Structure
- `index.html` - Semantic HTML structure and page content
- `style.css` - Cyber-luxe 3D glassmorphic styling, responsive layout, and theme variables
- `script.js` - Three.js WebGL scene, 3D cursor tilt engine, and theme toggle controller
